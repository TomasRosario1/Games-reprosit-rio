# Personagens originais

20 adultos low-poly (10 homens e 10 mulheres) criados proceduralmente para este projeto. Não usam modelos ou animações GTA. Malhas trianguladas no GLB, texturas urbanas originais e rig humano de 18 ossos com IK das pernas cozida nos clips.

Regenerar: `blender -b --python tools/generate_characters.py`. `source/human_source.blend` contém o primeiro corpo e rig para edição no Blender; os restantes GLB também podem ser importados. As identidades são estudos de guarda-roupa e não determinam a personalidade dos NPCs.

Os clips são estudos de locomoção e não captura de movimento. Precisam de afinação artística no equipamento do criador.
